DEPLOYMENT

Your cameras.
Your recording destinations.

Plan the E-VMS backend, operator access and storage before installing a desktop client.

01 / APPLICATION

Connect to an E-VMS backend.

The Windows desktop applications connect to an existing E-VMS backend. Installing a client alone does not provide the complete recording system.

02 / STORAGE

Allocate a recording path.

Storage must be mounted, reachable and writable from the recorder. Validate the path, allocate cameras and explicitly start recording.

A recording destination is configured storage. There is no separate E-VMS Recording Agent.

03 / ACCESS

Define who can use it.

Apply user roles and site/camera permissions. Match access to each operator’s responsibilities.
